在大模型训练过程中，数据质量对模型性能具有决定性影响。广告词作为训练语料中的噪声数据，会显著降低模型生成文本的质量和专业性。本过滤器通过系统化的清洗流程，有效识别并移除广告内容，确保训练数据的纯净度。

广告词对模型训练的危害
1. 语义污染
重复性污染：广告词的高频重复（如"限时优惠"、"立即购买"）会导致模型过度学习商业表达模式
语义偏移：促销用语会扭曲词语的原始语义分布，影响模型对正常语境的理解
2. 知识蒸馏失效
信息密度稀释：广告内容信息熵极低，拉低整体训练数据的知识浓度
逻辑结构破坏：广告文案的跳跃式逻辑会破坏模型对合理论证链条的学习

### 训练数据
* 训练集：17.9万条样本，正样本数约为10.7万条，负样本数约为7.2万条；
* 数据集经过了以下预处理步骤：
（1）分词：将文本分割为单词或子词；
（2）规范化：将文本转为小写，去除标点符号，处理特殊字符。
（3）停用词去除：删除对模型性能贡献不大的常用词。
（4）词干提取/词形还原：将单词还原为词根形式。
* 模型评估：交叉验证，模型预测准确率为97.4%。
