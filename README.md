# DataForge

-----------------------------------------------------------------------
数据是人工智能领域发展的基础要素之一。随着大规模预训练模型及相关技术不断取得突破，在相应研究中使用高效数据处理工具提升数据质量变得越来越重要。DataCollector2集成了包含清洗、敏感词过滤、广告词过滤、语料质量自动评估等功能在内的多个数据处理工具与算法，为中国AI大模型提供安全可信的主流数据。

DataForge支持以下特性：

* 打造丰富且满足国家意识形态价值观的中文高质量数据。

* 通过数据处理逻辑，各环节处理逻辑差异会产生不同版本、适配不同需求的数据集。

* 可从原始html/text快速清洗得到高质量中文数据，注重敏感信息滤除，避免隐私泄露风险。

## 大模型预训练语料的整体处理流程

大模型预训练语料清洗流程，共包括以下6个模块：

1. 数据收集：负责从多个源获取大量未经处理的文本数据。该模块可通过修改数据链接的方式用于多种数据类型或数据来源的下载，具有广泛的适用性。构建大型数据集需要海量的原始文本数据资源，本任务中需要下载近PB的数据，这对网络带宽要求极高，因此，采用了支持多设备节点并行下载的方案，并对下载任务进行统一调度管理，以确保整个数据获取过程的高效性和稳定性。
2. 数据预处理：从数据中提取出对研究有帮助的内容，即提取出所有语言类型为中文的文本数据。通过修改语言类型设置，也可用于其他单语言数据或多语言数据的提取。通过综合评估三种评测方法langid、langdetect和fastText，选用了效率较高、文本检测准确率也较高的fastText算法进行文本检测。为了尽可能多地保存中文数据并避免有效数据损失，以文本中的行作为语言判断的单位。
3. 篇章级过滤：通常中文提取后的数据中仍存在较多问题，不能直接用于构建训练数据集。通过采用两个过滤器进行内容的过滤：网页开始和结尾截取和完整句子检测。在去除不良文本时，选择以篇章作为不良文本的检测单位。通过检测每篇文章中包含的不良词汇表中的词汇，并计算不良词汇的出现次数以及占全文的比重，以此来判断整段文本是否不良文本。不良文本的关键是不良词汇的构建。此外，还支持对不同类别的不良词汇进行不同粒度的检测，通过调整不同类别对应的阈值实现不同严格程度的检测。
4. 样本间去重：针对文本进行样本间去重，我们采用了先局部再整体，先精确再模糊的实现方案。具体流程如下：（1）数据分组与分批处理：结合计算资源、存储资源和计算时效性，对预处理后的数据进行分组和分批去重，以减少资源浪费并缩小后续整体去重的数据规模，按数据来源和时间进行分组分批；（2）精确去重：在每组数据去重过程中，先进行精确去重，通过计算文档的哈希值并进行精确匹配，由于其计算过程简单，整个处理过程既快速又高效。（3）模糊去重：在精确去重的基础上进一步模糊去重，模型去重分两阶段优化效率，第一阶段（粗筛）：使用SimHash算法生成 128位哈希值，并通过比较海明距离来识别可能相似的数据，能够较大程度减少长文本间的相似度计算开销。第二阶段（精筛）：基于Jaccard相似度计算，并采用前缀剪枝策略进行优化。即将文档按全局词表排序，仅对前缀含相同单词的文档分组计算，排除不可能满足阈值条件的分组，进一步减少了计算量。通过这种分阶段处理减少了超过90%的冗余计算，并实现精确去重与模糊去重双重过滤，既保证了去重效率，有提高了处理效率。
5. 样本内去重：对于文档内部的篇章、段落、句子级重复冗余，重复模式相对比较复杂，有编辑修改或网页错乱导致的多次重复出现的篇章或段落，也有句子和短语重复堆叠的垃圾信息，需要采用n-gram等比较细粒度的统计分析规则进行综合判定，由于重复范围限定在单个文档内部，所以不同文档可以完全并行化处理。
6. 数据质量筛选（中文/英文）：经过上述步骤可以筛去文本中的正文无关内容和重复数据，但表达混乱的文本并不能被很好的识别。通过采用当前颇受认可的困惑度筛选方式，从已有数据中筛选出语句通顺的文本，以此提高数据整体质量。首先采用权威语料库（含人民网新闻语料、百科类高质量数据）训练轻量级的鹏城脑海模型，将待检测数据处理后逐条输入模型，并利用模型输出结果计算文本困惑度。困惑度越低表示文本质量越高，通过保留困惑度低于阈值的数据来保证数据的质量。为了进一步优化大规模数据质量筛选的效率，对文本数据进行分块并行化处理，提高处理速度，同时采用增量学习方法，使模型在新数据到来时快速更新，而不是重新训练整个数据集。
7. 脑海模型研制过程中，概含了语料的抽检评估工作，语料的抽检评估分为以样本为评估单位和以不同类型的数据集为评估单位进行评估。
   样本数据评估流程：（1）每一批清洗后的数据，根据数据类型抽样出2000条样本数据；（2）人工抽查抽样的2000条样本中的不合格样本，并标记不合格的原因，统计不合格的比例。（不合格的样本包含但不限于涉及知识产权、商业秘密评估，涉民族、信仰、性别等、还包含有怪异符号、前后表述语义内容相差很大、含有大量广告信息、公式格式错误、字符编码错误等内容）
数据集评估：整个数据集中，若不合格的样本占比大于或等于1%,则需对数据进行针对性的再次清洗；若经过调试，数据质量问题无法得到进一步解决时，则认为该数据集不可用于脑海模型的训练。
数据标注：对经过筛选的数据集进行详细的标记处理，包括赋予每个数据样本唯一标识符（ID）、数据质量等级标识（共五级）、以及记录其来源信息等。其中数据质量分级详情如下：
## 数据质量分级详情
| 等级          | 说明     | 
|:--------------|:--------|
| 1             | 数据不存在特殊怪异符号、错误、乱码、无效网页链接、理工科公式错误等；    | 
| 2             | 数据在逻辑上连贯，语义上一致，没有出现自相矛盾或不相关内容；           |
| 3             | 数据符合事实知识，不包含虚构或误导性的信息；                          |
| 4             | 数据包含一定的信息量和知识量，以及具有一定的学术价值和深度；            |
| 5             | 数据在领域上展现出高度多样性，涵盖不同的主题、风格、领域和语言；        |
